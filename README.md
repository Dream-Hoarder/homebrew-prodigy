# Dream-Hoarder Prodigy

## How do I install these formulae?

`brew install dream-hoarder/prodigy/<formula>`

Or `brew tap dream-hoarder/prodigy` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dream-hoarder/prodigy"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
